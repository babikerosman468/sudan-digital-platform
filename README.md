# Sudan Digital Platform

Evidence-based digital knowledge, research and analytical infrastructure for Sudan.

## Stack
- Next.js App Router
- Vercel
- Neon PostgreSQL
- GitHub
- Termux/Linux workflow

## Initial scope
Public MVP with Sudan Monitor, Research Hub, evidence architecture, platform modules and roadmap. Database schema is in `db/schema.sql`.

## Principle
Information -> Knowledge -> Understanding -> Constructive Cooperation

## Safety
The platform is non-partisan and evidence-oriented. FACT, ANALYSIS, FORECAST and COMMENTARY must remain distinguishable.
